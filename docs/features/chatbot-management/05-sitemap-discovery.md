# 2.4 Sitemap Discovery

## Discover URLs via Sitemap — `POST /api/v1/chatbots/{id}/sitemap/discover`
- [ ] Triggers sitemap URL discovery for the chatbot
- [ ] `202 Accepted` on successful submission
- [ ] `404 Not Found` for non-existent chatbot
- [ ] `403 Forbidden` for unauthorized access

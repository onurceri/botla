## 2.8 ConfirmModal Component

- [ ] Modal displays icon, title, and description
- [ ] Confirm button triggers the action
- [ ] Cancel button dismisses the modal
- [ ] Clicking backdrop dismisses the modal
- [ ] Escape key dismisses the modal
- [ ] Focus is trapped inside modal while open
- [ ] Focus returns to trigger element on close
- [ ] `aria-modal="true"` and `role="dialog"` are set
- [ ] Modal is fully keyboard accessible

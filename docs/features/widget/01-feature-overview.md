# 1. Feature Overview

A zero-dependency embeddable chat widget built with Preact 10 + Vite 7, compiled to a single IIFE bundle (`widget.js`) and deployed to Cloudflare Pages. Runs inside Shadow DOM for complete style isolation from the host page. Turkish-first UI. Communicates with the backend via public API endpoints.

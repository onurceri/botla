## 2.16 Responsive Layout

- [ ] On viewport < 480px width: drawer is full-width, full-height
- [ ] On viewport < 480px width: bubble is smaller
- [ ] On viewport < 480px width: suggestions stack vertically
- [ ] Safe area insets are respected (notch, home indicator)
- [ ] Landscape orientation is supported
